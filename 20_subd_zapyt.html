  Пам’ятка: запит у SQL і в конструкторі Access
  
    
    
  • SELECT — які поля показати (у конструкторі Access — прапорець «Вивід на екран»).
    • 
    
  • FROM — з якої таблиці брати дані.
    • 
    
  • WHERE — умова відбору (рядок «Умови відбору»). Умови в одному рядку конструктора з’єднуються через AND (І), у різних рядках — через OR (АБО).
    • 
    
  • ORDER BY … ASC / DESC — сортування за зростанням / спаданням (рядок «Сортування»).
    • 
    
  • «містить» у SQL записують як LIKE '%роман%'; в Access замість % використовують *: Like "*роман*".
    • 
    
  • Фільтр перед сортуванням економить роботу. Сортування вибором для m рядків робить m·(m − 1)/2 порівнянь. Для 12 рядків це 66 порівнянь, а для 4 відібраних — лише 6.
    • 
    
  • Порядок етапів тут спрощено. За стандартом SQL логічний порядок такий: FROM → WHERE → SELECT → ORDER BY. Засіб сортує до вибору стовпців, щоб можна було сортувати й за полем, яке не показується. Справжні СУБД також вибирають власні, швидші алгоритми сортування та пошуку.
    • 
  






  Інструкція для вчителя
  
    
    
  1. Запит як алгоритм (8 хв). Вкладка «Запит на вибірку», готовий запит (книги після 1900 року, за назвою). Кроком «рядок» пройдіть фільтрування: таблиця ліворуч, рядок за рядком, ✓ або ✗. Звертайте увагу на умову в алгоритмі й на те, як росте результат праворуч.
    2. 
    
  2. Сортування (7 хв). Кроком «крок» пройдіть перший прохід сортування вибором: i — місце, яке заповнюємо, k — найкращий кандидат, j — рядок, з яким порівнюємо. Потім «етап» або «Авто». Покажіть лічильник порівнянь.
    3. 
    
  3. Учні складають запити (8 хв). Завдання: «романи з бібліотеки, яких є хоча б 2 примірники, від найновішого», «учасники зі Львова, які набрали понад 80 балів, за балами». Порівняйте кількість порівнянь із фільтром і без нього. Покажіть різницю між «=» та «містить» (у Жанрі є «роман у віршах»).
    4. 
    
  4. Перевірка (7 хв). Вкладка «Передбач результат»: скільки рядків поверне запит, чи пройде рядок через фільтр, хто стане на наступне місце. Фронтально або на телефонах.
    5. 
    
  5. Пошук (5 хв). Вкладка «Пошук за ключем»: перебір проти половинного поділу. Спробуйте ключ, якого немає в таблиці. Зв’язок з уроком 29.10: ключове поле має індекс.
    6.
