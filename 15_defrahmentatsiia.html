Операції з файлами

Один кластер — найменша частина диска, яку ОС виділяє файлу. Тут 1 кластер = КБ.
Диск: кластерів, зайнято 0, вільно 0
Головка читання: —
Номер кластера = номер рядка (ліва колонка) + номер стовпця (верхній рядок). Натисніть на файл у легенді, щоб підсвітити його кластери.
Виберіть сценарій або запишіть кілька файлів, видаліть один-два з них і запишіть новий — побачите, як виникає фрагментація.

Дії для демонстрації

Читання показує, скільки разів головка «перестрибує» між фрагментами. Дефрагментація переставляє кластери так, щоб кожен файл став суцільним.

Таблиця розміщення файлів (спрощена FAT)

Для кожного файлу ОС зберігає ланцюжок кластерів. Кожна рамка — один суцільний фрагмент.

Дефрагментація: до і після

Переміщення головки — сумарна відстань у кластерах, яку головка проходить під час читання всього файлу.

Що показує засіб

  • файл зберігається не обов'язково в суцільній ділянці диска;
  • після видалення файлів утворюються «дірки» потрібного і непотрібного розміру;
  • новий файл заповнює дірки і стає фрагментованим;
  • читання фрагментованого файлу вимагає більше переміщень головки, тобто більше часу;
  • дефрагментація перебудовує розміщення, але сама є тривалою операцією.
